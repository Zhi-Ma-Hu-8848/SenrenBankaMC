# 千恋＊万花 · 网易 MC 1-1《亚瑟王》

当前只收录完整 **1-1《亚瑟王》**：出租车醒来、与芦花重逢、志那都庄、建实神社、拔刀与折刀、丛雨登场、芳乃及最后的求婚。共 807 条原作简中台词及旁白；保留“说实话／敷衍过去”选项，单次阅读分别为 798、802 句。没有接入 1-2 或 1-3。

包含 350 段配音（349 句有配音，含一句双人同时发声）、11 首音乐、8 位角色的 174 种立绘组合及本章背景、CG、Q 版场景。对话框和底部菜单栏背景均为 **30% 不透明度**，文字保持不透明。

剧情画面固定为 **16:9** 并居中显示，背景保留原图比例，人物、CG 与 Q 版插图按同一画面缩放。窗口多出的两侧或上下区域使用当前场景的模糊暗色图片填充；调整窗口大小会更新布局。标题和章节结束画面也采用此显示方式。
背景贴图宽高各缩小一半（1110×640 或 960×540），显示时开启平滑采样。

立绘按原作的角色偏移、远近缩放与图片裁切坐标放置，普通距离采用接近原作的半身构图，三人场景保留左右间距与身高差。
立绘先按 **1000×2048** 的像素密度合成，再依据本章全部镜头裁掉始终在屏幕下方的部分；输出宽度为 1000，高度按图片的实际可见范围保留。平滑采样、人物大小和位置保持一致。

## 直接在游戏中测试

这是网易 Python 2.7 ModSDK 模组。通过本机 MCDK 直接启动网易 3.10.0.420447 游戏客户端，无需开发者工作台。

```powershell
.\tools\launch_game_test.ps1
```

默认使用 `D:\MCDevTool\v1.6.1\mcdk.exe` 和本机 3.10 客户端；可传 `-McdkPath`、`-GamePath` 指定其他路径。脚本加载两包，进入独立的 `SENREN_PROLOGUE_TEST` 世界，保留已有世界和阅读存档。启动前关闭现有游戏客户端。

进入世界后，右上角 HUD 显示“千恋＊万花”按钮。点击按钮进入剧情标题界面；关闭剧情后，按钮继续保留，可再次点击进入。也可按 F6 打开。

## 进度选择

点击底部“菜单”返回标题，再点击“选择进度”。所有进度都可直接进入，无需先读完或解锁。

- 点击场景快捷入口，或翻页点击任意一句。
- 在游戏原生输入框中填写 **1–807** 的句子编号，再点击“进入”。没有自制数字键盘。
- 跳入选择分支时自动进入对应分支；跳回选择前可重新选择；跳到共同后续时保留当前分支，没有分支存档时默认“说实话”。
- 跳转会恢复该句的背景、人物、CG、配音和音乐，并保存进度。

## 阅读操作

- 点击画面、空格、回车或右方向键：显示本句全文，再次操作进入下一句。
- 左方向键／“上一句”：返回上一句。
- “自动”：等待文字与配音结束后推进；选项和进度菜单会暂停自动阅读。
- “回看”／H：查看当前路线的对话记录。
- “重播”：重新播放本句配音；“声音”：静音或恢复声音。
- “存档”：手动保存，每句也会自动保存。旧芦花短版存档可继续使用。
- “菜单”／M：回到标题。标题可按 S 开始、C 继续、P 选择进度；阅读时 P 也可直接打开进度选择。进度列表用 PgUp、PgDn 翻页。
- “返回 Minecraft”：关闭剧情，停止模组声音并恢复原版音乐。

## 内容与构建

`content/prologue.json` 保留全部 807 句的原始场景及文本编号；`source_manifest.json` 记录原始资源来源和校验，`standing_manifest.json` 记录立绘的原图层及组合。

1-1 的文本完整接入。Q 版 E-mote 演出采用对应动作的静态关键帧，竖幅 CG 使用静态视窗；复杂相机、过渡和粒子未逐项复刻。当前版本是简易剧情适配。

构建工具位于仓库根目录 `tools/`：`chapter_assets.py`、`chapter_illustrations.py` 提取并组合本地资源，`build_content.py` 生成两包，`package_addon.py` 生成分发包。
